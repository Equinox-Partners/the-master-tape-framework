# Minimum Sufficient Context

## Principle

Load the smallest set of current, authoritative information that can materially affect the task.

## Why

More context is not always better. Excess context increases cost, introduces stale claims, and makes authority harder to distinguish.

## Stop condition

Stop loading documents when additional information is unlikely to change the answer or action.
