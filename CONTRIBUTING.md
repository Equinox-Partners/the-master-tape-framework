# Contributing

Thank you for helping improve The Master Tape.

## Before opening a pull request

1. Open an issue for architecture-level changes.
2. Keep examples generic and free of personal or company information.
3. Update the revision and `updated_at` of every changed canonical document.
4. Add or update the corresponding Registry entry.
5. Run `ruby scripts/validate.rb`.

Prefer small changes backed by a real failure or use case. The project values simpler rules over speculative automation.
